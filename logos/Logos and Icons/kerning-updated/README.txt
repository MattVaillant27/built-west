Built West kerning-updated artwork package

This package contains new versions of all supplied logo-bearing artwork, with the W–e spacing in “West” corrected to the current stacked primary logo. The original artwork files remain unchanged.

Artwork files include the 3000×3000 cover (PNG and SVG), Instagram, LinkedIn and YouTube profile images, the episode template, the 2560×1440 YouTube banner, and the 1536×1024 brand palette sheet. The separate headshot cutout is included unchanged because it contains no logo.

The palette sheet’s stacked, horizontal and wordmark examples were updated; standalone monogram and app-icon artwork was left unchanged. The corrected SVG logo variants are in corrected-svg-logo-variants/.

Drive did not grant write access, so these new files are in the project output folder and originals were not replaced.
